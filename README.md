# Bayesian Optimization — Reproduction Benchmark

A student project to learn about Bayesian optimization by reproducing a small part of a published benchmark.

## Objective

Compare selected Gaussian process (GP) and random forest (RF) strategies with random search using the published Crossed barrel dataset.

## Current status

Initial planning and reading. Implementation and experiments have not started. This README will be updated as the project develops.

## References

- Benchmark paper: *Benchmarking the performance of Bayesian optimization across multiple experimental materials science domains* (2021). [Read the paper](https://doi.org/10.1038/s41524-021-00656-9).
- Original code and datasets: [PV-Lab/Benchmarking](https://github.com/PV-Lab/Benchmarking).
- Crossed barrel dataset: Gongora et al., *A Bayesian experimental autonomous researcher for mechanical design*, Science Advances 6, eaaz1708 (2020).

This is an independent learning project, not the authors’ official implementation.
